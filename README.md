# 📊 Student Performance & Placement Analysis Dashboard

> End-to-end analytics project on 500 student records to identify the key factors influencing placements, internship outcomes, academic performance, and salary packages.

![Dashboard](dashboard_screenshot.png)

---

## 🧩 Problem Statement

Educational institutions often struggle to understand which factors have the greatest impact on student placements.

Key questions:

* Does internship experience improve placement chances?
* Which departments achieve the highest placement rates?
* How do communication skills and academic performance affect employability?
* Which departments receive the highest salary packages?

## 🔍 Key Business Insights

### 🎓 Placement Performance

| Status     | Students |
| ---------- | -------- |
| Placed     | 203      |
| Not Placed | 297      |

* Overall placement rate stands at **40.6%**
* More students remain unplaced than placed, highlighting opportunities for skill development and placement preparation

### 💼 Internship Impact

| Internship Status | Placed Students |
| ----------------- | --------------- |
| Completed         | 117             |
| Not Completed     | 86              |

* Students who completed internships achieved significantly better placement outcomes
* Internship exposure improves employability and industry readiness

### 🏢 Department-Wise Placement

| Department  | Placed Students |
| ----------- | --------------- |
| Electronics | 49              |
| Civil       | 45              |
| CS          | 41              |
| IT          | 37              |
| Mechanical  | 31              |

* Electronics department achieved the highest number of placements
* Mechanical department recorded the lowest placement count

### 💰 Average Package by Department

| Department  | Avg Package (LPA) |
| ----------- | ----------------- |
| Mechanical  | 8.15              |
| IT          | 7.77              |
| CS          | 7.63              |
| Civil       | 7.49              |
| Electronics | 7.22              |

* Mechanical students secured the highest average package
* Package distribution remains competitive across all departments

### 🗣️ Communication Skills Analysis

* Placed students achieved higher communication scores compared to non-placed students
* Communication skills emerged as an important employability factor

---

## 💡 Recommendations

1. Increase internship participation across all departments
2. Strengthen communication and aptitude training programs
3. Provide additional placement support for low-performing departments
4. Encourage students to complete more academic and practical projects
5. Implement targeted mentoring for students with backlogs
