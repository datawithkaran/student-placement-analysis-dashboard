# Student Placement Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing student academic performance and placement trends using Excel, SQL, and Power BI. The dashboard provides insights into placement rates, department-wise performance, communication skills impact, internship impact, and salary package distribution.

---

## 🛠 Tools & Technologies Used
- Excel / Google Sheets
- SQL (MySQL)
- Power BI

---

## 📊 Key Dashboard Features
✔ Total Students KPI  
✔ Placed Students KPI  
✔ Average Package Analysis  
✔ Highest & Lowest Package  
✔ Department-wise Placement Analysis  
✔ Internship Impact on Placement  
✔ Communication Score Analysis  
✔ Interactive Slicers  
✔ Key Business Insights

---

## 📈 Key Insights
- Internship completed students had higher placement rates.
- Students with strong communication skills received better placements.
- CS and IT departments achieved higher average salary packages.
- Students with fewer backlogs showed better placement performance.
